# =============================================================================
# SVI-DAG: fully pinned lockfile (direct + transitive).
#
# Every package needed to run SVI-DAG and all five baselines (ProDAG, DiBS,
# DDS / VI-DP-DAG, BayesDAG, BCD Nets), pinned to an exact version.  This is a
# *complete* lock, not just the direct dependencies -- installing it gives the
# same package set that produced every number in ``paper_results_reproduce/``,
# regardless of when the install happens or what PyPI has published since.
#
# Validated on Linux with an NVIDIA A100 GPU, Python 3.11.
#
# For the short, human-readable list of *direct* dependencies and why each one
# is here, see ``requirements-direct.txt``.  Install this file, not that one.
#
# Installation
# ------------
# This file is the CPU-portable half of the lock: it pins everything that is
# not CUDA specific and installs on any platform.  The NVIDIA CUDA 12.4 wheels
# that used to sit at the bottom of this file now live in
# ``requirements-cuda12.txt``, so neither install path requires editing a
# lockfile by hand:
#
#   CPU-only : pip install -r requirements.txt
#   GPU      : pip install -r requirements.txt -r requirements-cuda12.txt
#
# Easiest is to let ``setup_env.sh`` do it -- it builds the conda environment,
# detects whether a GPU is present, and installs the right pair.  See README.md.
#
# The bundled baselines under ``other_algorithms/codes_jax/`` are imported via
# ``sys.path`` injection by their wrappers and must NOT be pip-installed --
# their upstream ``setup.py`` files declare unpinned dependencies that would
# pull ``jupyter`` and float the JAX pins away from the versions locked here.
# See README.md, "Installation".
#
# Regenerating: see ``scripts/lock_requirements.md``.
# =============================================================================
