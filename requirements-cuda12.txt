# =============================================================================
# SVI-DAG: NVIDIA CUDA 12.4 wheels (GPU only).
#
# The GPU half of the lockfile.  Install it ALONGSIDE requirements.txt, never
# instead of it:
#
#     pip install -r requirements.txt -r requirements-cuda12.txt
#
# Split out of requirements.txt so that neither the CPU nor the GPU install
# path requires commenting lines out of a lockfile by hand.  The pins are
# unchanged from when the two lived in one file, so the installed package set
# is identical to the one that produced every number in
# ``paper_results_reproduce/``.
#
# Every version here is in the CUDA 12.4 family so the JAX plugin and the
# runtime libraries cannot desync.  A newer wheel set produces ``Bus error`` or
# ``CUDNN_STATUS_INTERNAL_ERROR`` at JAX startup -- that is the signature of an
# ABI mismatch, and the fix is to reinstall exactly these versions.
#
# Requires an NVIDIA driver new enough for CUDA 12.4 (>= 550.54.14, or any
# driver reporting "CUDA Version: 12.4" or higher in ``nvidia-smi``).
#
# AMD/ROCm and Apple Silicon are NOT covered by this file; see README.md.
# =============================================================================
